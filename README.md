A clean, responsive, and modern calculator designed for **Growtopia** doctors and surgeons to simulate **Autoclave sterilization cycles**, calculate item yields (Stitches, Sponge, Antibiotic, Scalpel), track recycled tool returns, and calculate net profit/loss in World Locks (WL) and Diamond Locks (DL).

---

## ✨ Features

- 🔄 **Two Calculation Modes:**
  - **Single Run:** Simulates a single autoclave cycle (20 dirty tools = items + 8 recycled tools).
  - **Full Loop (Until Exhausted):** Automatically simulates compounding cycles until tools run out.
- 💰 **Comprehensive Economy Analysis:** Computes Capital (Modal), Total Revenue, Net Profit/Loss (WL & DL), and ROI percentage.
- 🎛️ **Live Market Rate Tuner:** Customize market values for Stitches, Sponge, Antibiotic, and Scalpel with 1-click reset.
- 📱 **Modern Dark UI:** Styled with Tailwind CSS and Lucide Icons, responsive across desktop, tablets, and phones.
